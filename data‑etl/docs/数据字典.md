# 国元证券 TRAE 金科竞赛 — 数据字典

> 范围：`data-etl` 模块。原始数据位于项目根 `./data`，分层入库至 **MySQL（元数据）**、**ClickHouse（时序/明细/汇总）**、**MinIO（研报正文）**。

## 1. 总体架构

| 存储 | 库 / Bucket | 用途 |
| --- | --- | --- |
| MySQL | `gy_meta` | 资产/指标维度、研报索引、数据源清单、ETL 批次日志 |
| ClickHouse | `gy_dw` | 行情、指标、事件、新闻等海量时序数据（ODS/DWD/DWS 三层） |
| MinIO | `research-reports` | 研报 md 正文（数据库仅存对象路径索引） |

### 分层说明
- **ODS 贴源层**：一个原始数据源一张表，保留原始字段 + `source_file` / `batch_id` / `load_time`，不做业务过滤。
- **DWD 明细层**：清洗标准化（类型规整、空值处理、去重），并将多源新闻合并为统一视图。
- **DWS 汇总层**：面向看板的轻度聚合（每日新闻量、资产行情统计），由 `run_all.py` 在 ETL 后刷新。

## 3. MySQL 元数据层（`gy_meta`）

### 3.1 `dim_asset` 资产维度
来源：`目标资产价格变量/代码对照.csv`

| 字段 | 类型 | 业务口径 |
| --- | --- | --- |
| asset_id | BIGINT PK | 主键 |
| category | VARCHAR(32) | 大类：中国权益 / 全球权益 / 大宗商品 / 外汇 / 全球债券 / 另类 |
| name | VARCHAR(64) | 资产名称（与 csv 文件名一致，唯一键） |
| wind_code | VARCHAR(32) | Wind 代码 |
| field_type | VARCHAR(16) | 字段类型：`close`（价格/指数）/ `yield`（收益率，单位 %） |
| trade_calendar | VARCHAR(128) | 交易日历描述（如 上交所交易日 / NYSE 等） |
| start_date / end_date | DATE | 数据起止日期 |
| row_count | INT | 原始条数 |
| status | VARCHAR(16) | `ok` / `缺失`（如"全球高收益债"无对应数据文件） |
| remark | VARCHAR(512) | 业务口径备注（如是否复权、单位） |
| source_file | VARCHAR(255) | 源 csv 相对路径 |
| batch_id | VARCHAR(64) | ETL 批次号 |

### 3.2 `dim_indicator` 指标维度
来源：`指标集1_数据.xlsx` 每个 sheet 的每个序列

| 字段 | 类型 | 业务口径 |
| --- | --- | --- |
| sheet_code | VARCHAR(16) | sheet 编号 X01–X31（唯一键之一） |
| seq_name | VARCHAR(16) | 序列名 序列1..序列N（与 sheet_code 联合唯一） |
| start_date / end_date | DATE | 该序列数据起止 |
| row_count | INT | 该序列行数 |
| remark | VARCHAR(512) | 指标业务口径（宽表转长表，序列含义待业务方补充） |

### 3.3 `report_index` 研报索引
来源：`全球资金信息摘要.zip` 解压后的 md 文件（**正文存 MinIO，本表只存索引路径**）

| 字段 | 类型 | 业务口径 |
| --- | --- | --- |
| title | VARCHAR(512) | 研报标题（取自文件名，解析 `日期-机构-标题.md`） |
| publish_date | DATE | 发布日期（从文件名解析） |
| institution | VARCHAR(32) | 机构标识：机构A/B/C/E/H 等（从文件名解析） |
| minio_bucket | VARCHAR(64) | MinIO bucket：`research-reports` |
| minio_object_key | VARCHAR(512) | MinIO 对象路径，如 `reports/上科大版本摘要/xxx.md`（**正文索引**） |
| source_zip / source_file | VARCHAR | 来源压缩包 / zip 内相对路径 |
| file_size / file_md5 | BIGINT / VARCHAR(32) | 文件字节数 / md5（用于去重与完整性校验） |

### 3.4 `data_source` 数据源清单
记录每一个原始文件，用于校验不遗漏。唯一键 `file_path`。字段：`category / file_path / file_name / file_type / raw_rows / loaded_rows / target_table / status / last_load_time / remark`。

### 3.5 `etl_batch_log` ETL 批次日志
字段：`batch_id / task_name / source_file / target_table / raw_rows / loaded_rows / failed_rows / status(running/success/failed) / start_time / end_time / message`。

## 4. ClickHouse 时序层（`gy_dw`）

### 4.1 ODS 贴源层

#### `ods_market_price` 行情价格
来源：`目标资产价格变量/` 下 39 个 csv 合并。分区 `toYYYYMM(trade_date)`，排序 `(asset_code, trade_date)`。

| 字段 | 类型 | 业务口径 |
| --- | --- | --- |
| asset_code | LowCardinality(String) | 资产代码（取 Wind 代码，缺失用名称） |
| asset_name | String | 资产名称 |
| category | LowCardinality(String) | 大类 |
| field_type | LowCardinality(String) | close / yield |
| trade_date | Date | 交易日 |
| value | Nullable(Float64) | 收盘值（close）或收益率（yield，单位 %） |
| source_file | String | 源文件相对路径 |
| batch_id / load_time |  | 批次号 / 入库时间 |

#### `ods_indicator` 衍生指标（长表）
来源：`指标集1_数据.xlsx` 31 个 sheet 宽表转长表。分区 `toYYYYMM(trade_date)`，排序 `(sheet_code, seq_name, trade_date)`。

| 字段 | 类型 | 业务口径 |
| --- | --- | --- |
| indicator_code | LowCardinality(String) | 如 `X01_序列1` |
| sheet_code / seq_name | LowCardinality(String) | sheet 编号 / 序列名 |
| trade_date | Date | 指标日期 |
| value | Nullable(Float64) | 指标值（空值保留） |

#### `ods_event_calendar` 事件日历
来源：`日历数据.xlsx`。分区 `toYYYYMM(occur_date)`。

| 字段 | 类型 | 业务口径 |
| --- | --- | --- |
| indicator_name | String | 指标名称（如"澳大利亚12月AIG/PWC制造业表现指数"） |
| occur_date | Date | 发生日期 |
| occur_time | String | 发生时间 |
| home_country | LowCardinality(String) | 国家代码（原始为数字编码，如 601=澳大利亚，保留原始值） |
| indicator_former / forecast / fact | Nullable(Float64) | 前值 / 预测值 / 公布值 |

#### `ods_news_cailianpress` 财联社新闻
来源：`新闻/无标题.csv`（无表头，按 11 列位置命名）。分区 `toYYYYMM(publish_date)`。

| 字段 | 类型 | 对应原始列 | 业务口径 |
| --- | --- | --- | --- |
| news_id | UInt64 | 第1列 | 新闻 ID |
| title | String | 第2列 | 标题 |
| content | String | 第3列 | 正文 HTML |
| source | String | 第4列 | 来源（财联社 / 财联社星矿 等） |
| extra_flag | String | 第5列 | 原始分类标记（疑似序号/分类） |
| tags | String | 第6列 | 标签（多为空） |
| stock_codes | String | 第7列 | 关联股票 JSON，如 `[{"stocks_code":"sh603383"}]` |
| publish_ts / crawl_ts | UInt64 | 第8/9列 | 发布 / 采集 unix 时间戳 |
| publish_date | Date | 第10列 | 发布日期 |
| row_no | UInt32 | 第11列 | 原始行序号 |

#### `ods_twitter` Twitter 舆情
来源：`科技.csv`，保留全部 31 个原始字段（文本类 String，计数类 Nullable(Int64)，时间类 String），并派生 `publish_date`（由 `created_at` 解析，失败置 1970-01-01）。分区 `toYYYYMM(publish_date)`，排序 `(publish_date, tweet_id)`。

主要字段：`tweet_id / user_name / author_display_name / text / lang / like_count / reply_count / retweet_count / quote_count / view_count / created_at / publish_date` 等。

#### `ods_wechat_article` 公众号文章
来源：`公众号.xlsx`。分区 `toYYYYMM(publish_date)`。

| 字段 | 类型 | 业务口径 |
| --- | --- | --- |
| publish_date | Date | 发布日期 |
| url | String | 文章链接 |
| title | String | 文章标题 |
| related_party | String | 相关方 |

#### `ods_futures_turnover` 商品期货日成交额
来源：`商品期货日成交额.xlsx`。分区 `toYYYYMM(trade_date)`。

| 字段 | 类型 | 业务口径 |
| --- | --- | --- |
| trade_date | Date | 交易日 |
| turnover | Float64 | 成交额（万亿元） |

### 4.2 DWD 明细层

- `dwd_market_price_daily`：与 `ods_market_price` 同结构，引擎 `ReplacingMergeTree(load_time)` 按 `(asset_code, trade_date)` 去重。
- `dwd_event_calendar`：与 `ods_event_calendar` 同结构（去 source_file），`ReplacingMergeTree` 去重。
- `dwd_news_unified`：统一新闻明细，合并财联社 / Twitter / 公众号。字段 `news_id / source_type(cailianpress/twitter/wechat) / title / content / publish_date / publish_ts / stock_codes / raw_url / batch_id`。分区 `toYYYYMM(publish_date)`，排序 `(source_type, publish_date, news_id)`。

### 4.3 DWS 汇总层（由 `run_all.py` 刷新）

- `dws_news_count_daily`：每日各来源新闻量。引擎 `SummingMergeTree`，主键 `(publish_date, source_type)`，度量 `news_cnt`。
- `dws_market_asset_stats`：每个资产的行情统计（`min_date / max_date / row_cnt / last_value`，`last_value` 取 `argMax(value, trade_date)` 最新值）。
